# SURPRISE ME - منصة قوائم الأمنيات الاجتماعية

تطبيق ثنائي اللغة (العربية/الإنجليزية) مصمم لإدارة ومشاركة قوائم الأمنيات والهدايا بين الأصدقاء والعائلة.

## مميزات المشروع

- **واجهة ثنائية اللغة**: دعم كامل للغتين العربية والإنجليزية في جميع أنحاء التطبيق
- **التركيز الاجتماعي**: مشاركة قوائم الأمنيات والتفاعل مع قوائم الأصدقاء
- **بدون تجارة إلكترونية**: التركيز فقط على إدارة قوائم الأمنيات والمشاركة الاجتماعية
- **قوائم أمنيات متعددة**: إنشاء قوائم منفصلة للمناسبات المختلفة
- **إضافة العناصر يدويًا**: إضافة عناصر بروابط خارجية أو وصف أو صور
- **مشاركة قوائم الأمنيات**: عبر منصات التواصل الاجتماعي المختلفة (واتساب، سناب شات، تويتر، البريد الإلكتروني)
- **حجز الهدايا**: حجز العناصر من قوائم أمنيات الأصدقاء لتجنب التكرار

## تقنيات المشروع

- **الواجهة الأمامية**: React, TypeScript, Tailwind CSS, Shadcn UI
- **الخادم**: Express.js, Node.js
- **قاعدة البيانات**: PostgreSQL مع Drizzle ORM
- **المصادقة**: Passport.js
- **حالة التطبيق**: TanStack Query

## متطلبات التشغيل

1. Node.js (الإصدار 18 أو أحدث)
2. npm أو yarn
3. قاعدة بيانات PostgreSQL (للنسخة الإنتاجية)

## تثبيت المشروع

```bash
# استنساخ المشروع
git clone https://github.com/YOUR_USERNAME/surprise-me.git
cd surprise-me

# تثبيت المكتبات
npm install

# تشغيل المشروع للتطوير
npm run dev
```
